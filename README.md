# FocusFlow

**用 ChatGPT 保护注意力：早间规划，晚间微同步，给长期兴趣留位置。**

FocusFlow 是一个日常注意力管理 Skill。它帮助你保护当前主线、照顾长期兴趣，保留休息与自由时间，不要求逐项打卡或填满全天。

## 开始使用

在支持自定义 Skill 的环境中，按该环境的安装方式添加本仓库，保留 `SKILL.md` 与 `references/` 的相对位置。选中 FocusFlow 后发送：

> 帮我启动 FocusFlow。先和我沟通当前主线、长期兴趣、作息和提醒偏好，再配置早间规划和晚间微同步。

如果你使用的 ChatGPT 界面没有 Skill 安装入口，也可以把 [SKILL.md](SKILL.md) 和 [references/](references/) 中两份文件的完整内容粘贴到同一个对话，再发送上面的启动语。这是通过对话使用流程，不等于安装原生 Skill。

首次启动会逐步确定你的时区、早晚提醒时间、重复日、固定安排和关注方向。没有统一的默认作息，也可以先手动试用。周回顾、日历及健康数据都是可选项。

## 日常怎么用

- **早间**：查看简洁时间表和「今日速览」。
- **日间**：随时说“下午有事”“今天减量”，调整安排。
- **晚间**：用一句话同步影响明天的变化；没有变化可回复“照旧”，也可以跳过。
- **可选周回顾**：决定哪些事继续、减量或暂放。

## 平台与定时任务

目前主要面向 **ChatGPT**；Claude Code 等其他 AI 环境尚未验证。能够读取 Skill 不代表完整支持定时提醒。

定时任务按使用者确认的设置创建；如果没有可用的创建工具，FocusFlow 会提供可复制请求供你在 ChatGPT 中设置。安装 Skill 本身不会启动提醒。

任务不能直接读取项目文件，因此任务正文需要包含必要规则和基准状态；晚间反馈也不能假定会自动传给早间任务。有可用工具时更新任务，否则给出明确标记待同步的交接摘要。[官方任务说明](https://help.openai.com/en/articles/10291617-scheduled-tasks-in-chatgpt)

已检查指令结构和模拟对话行为；真实排程、通知和状态交接请在自己的账号中验证。个人状态无需提交到本仓库。
